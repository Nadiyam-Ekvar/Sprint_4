# В проекте реализованы юнит-тесты для класса `BooksCollector` с использованием `pytest`.

## Что покрыто тестами

Реализованы тесты для основных сценариев работы класса:

1. **Добавление новых книг**
   - проверка успешного добавления двух книг;
   - проверка, что книга с пустым названием не добавляется;
   - проверка, что книга с названием длиннее 40 символов не добавляется;
   - проверка, что одну и ту же книгу нельзя добавить повторно.

2. **Установка жанра книге**
   - проверка, что книге можно установить жанр из списка допустимых жанров.

3. **Получение жанра книги**
   - проверка, что у новой добавленной книги жанр по умолчанию пустой.

4. **Получение списка книг по жанру**
   - проверка, что метод возвращает книги только с указанным жанром.

5. **Получение словаря книг и жанров**
   - проверка, что после добавления книги корректно сохраняются в словаре `books_genre`.

6. **Получение книг, подходящих детям**
   - проверка, что книги с возрастным рейтингом не попадают в список детских;
   - проверка, что книги без возрастного рейтинга попадают в список книг для детей.

7. **Добавление книги в избранное**
   - проверка успешного добавления книги в избранное;
   - проверка, что одну и ту же книгу нельзя добавить в избранное дважды.

8. **Удаление книги из избранного**
   - проверка успешного удаления книги из списка избранного.

9. **Получение списка избранных книг**
   - проверка актуального содержимого списка избранных книг после добавления и удаления.

## Особенности реализации

- Для сценариев с одинаковой логикой и разными входными данными использована **параметризация** `pytest.mark.parametrize`.
- Некоторые тесты проверяют сразу несколько связанных методов, если это соответствует реальному пользовательскому сценарию.
